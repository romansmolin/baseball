# Бриф по проекту — помощник для фэнтези-бейсбола

Продукт — вспомогательный инструмент для игроков в фэнтези-бейсбол на внешних платформах
(Yahoo, ESPN и других). Здесь **нет** соревнований между пользователями, призов, лиг и
рейтингов. Решение и план: `docs/superpowers/specs/2026-11-18-fantasy-assistant-pivot-design.md`
и `docs/superpowers/plans/2026-11-18-fantasy-assistant-pivot.md`.

## Что умеет продукт

- **Игроки** (`/players`): поиск по MLB, карточка с аналитикой — сезон, форма за 7/14/30 игр,
  сплиты (vs LHP/RHP, дома/в гостях), ожидаемые метрики Statcast, статус на ростере, «outlook»-оценка.
- **Сравнение** (`/compare`): до четырёх игроков рядом, ссылка делится через `?ids=`.
- **Матчи** (`/games`, `/games/[gamePk]`): ближайшие игры, вероятные питчеры, погода, статус
  составов и статистическая оценка исхода (не прогноз и не совет по ставкам).
- **Мои команды** (`/teams`): черновики команд с платформой (Yahoo/ESPN/Other) и типом очков
  (points / 5x5). Команда нигде не «участвует» — это справочный черновик.
- **AI за кредиты**: анализ матча с прогнозом и подбором игроков (`game_analysis`, 300 кредитов), графики игрока (`performer_analytics`, 100 кредитов),
  автозаполнение. Кредиты списываются только при успешном ответе.

## Стек

Next.js 16 (App Router), React 19, TypeScript, Prisma 7 + PostgreSQL, SWR, Tailwind 4, Vitest,
better-auth, OpenAI Responses API. Архитектура — FSD; серверные слои route → controller →
service → repository (правила в `CLAUDE.md` и `docs/`).

## Данные

Только публичные источники MLB: **MLB Stats API** (статистика, сплиты, game log, расписание,
вероятные питчеры, погода, турнирная таблица) и **Baseball Savant** (CSV с ожидаемыми метриками).
Код — `server/providers/mlb/` и `server/providers/savant/`. FanGraphs и Baseball-Reference не
используются: их условия запрещают автоматический сбор. Других лиг (NPB, KBO) в данных нет.

## Расчёты

Оценки считаются детерминированно (`server/services/estimates/`, веса в `estimates.const.ts`).
AI получает готовые числа и только объясняет/выбирает среди переданных кандидатов; ответ с игроком
вне списка кандидатов отклоняется, и кредиты не списываются.

## Деньги

Покупка кредитов через внешний шлюз («Secure Processor»), реестр `CreditTransaction` (без колонки
баланса). Типы `TOURNAMENT_ENTRY_FEE` и `TOURNAMENT_WINNINGS` остаются в enum только ради истории.
